# Centro de Ayuda y Base de Conocimiento — Control Ganadero

Bienvenido a la documentación oficial y centro de soporte de **Control Ganadero**.
Este portal reúne las guías operativas, reglas de negocio, flujos de pantalla y resolución de problemas para la gestión integral de fincas ganaderas.

---

## Estructura de la Base de Conocimiento

Nuestra documentación se organiza en 5 áreas funcionales principales:

1. **Cuentas y Usuarios:** Inicio de sesión, registro de nuevas cuentas, perfil de finca y suscripciones.
2. **Inventario y Trazabilidad Animal:** Registro de animales, aretes oficiales, traslados entre fincas, lotes y potreros.
3. **Sanidad y Reproducción:** Planes de vacunación, tratamientos veterinarios, control de celos, inseminación y partos.
4. **Producción y Básculas:** Pesajes de ganado, integración Bluetooth con básculas ganaderas y control lechero diario.
5. **Offline y Reportes:** Trabajo sin conexión a internet, sincronización automática de datos y generación de reportes.

---

### ¿Cómo navegar por este portal?
Utilice el **menú lateral izquierdo** para explorar las categorías y submódulos disponibles, o utilice la **barra de búsqueda superior** para encontrar respuestas rápidas a cualquier consulta o mensaje de error.
